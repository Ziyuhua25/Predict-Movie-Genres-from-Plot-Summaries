# 第三部分：SBERT 官方六组数据汇报稿

预计时长：5.5–6.5 分钟。

在 TF-IDF 词汇基线之后，我负责语义模型部分。我的核心问题不是只看模型分数，
而是进一步判断：SBERT 是真的利用了剧情语义，还是仍然主要依赖关键词？

我们使用 `all-MiniLM-L6-v2`，把每段剧情概述转换为一个 384 维向量。比如
“侦探调查神秘谋杀”和“警察试图侦破杀人案”用词不同，但语义接近。我们的假设
是，句子向量应当能够捕捉超越具体关键词的叙事信息。

模型流程是：先做空白字符规范化，不删除词；然后用冻结的 MiniLM 编码；最后
使用 18 个 One-vs-Rest 逻辑回归分类器。选择 One-vs-Rest 是因为电影类型是多
标签任务，一部电影可以同时属于 Action、Comedy 和 Drama。每个分类器独立判断
一种类型是否存在，因此可以同时输出多个标签。

我们在验证集上选择全局阈值 0.25。默认阈值 0.50 的验证集 Macro-F1 是 0.442，
调到 0.25 后提升到 0.552，绝对提升 0.110，而编码器和分类器都没有改变。官方
原始测试集上，Macro-F1 是 0.548，Micro-F1 是 0.624。

成功案例只举一个：*Next Goal Wins* 描述一支长期失败的足球队最终实现转变并
获胜。模型正确预测 Comedy 和 Drama，说明它能利用“失败—转变—胜利”的完整
叙事轨迹，而不只是显式的类型词。

失败案例也举一个：*History of the World: Part I* 中，模型识别出历史内容，却
没有识别喜剧化的表达方式，预测成 Drama 和 History。这说明“理解发生了什么”
不等于“理解故事以什么语气和框架呈现”。

因此我们使用官方六组固定输入做干预实验。每组都是同样的 1,198 部电影，模型、
预处理、标签顺序和阈值全部固定，不对扰动数据重新训练。

原始 Macro-F1 是 0.548。把所有词在局部 10 词窗口内打乱后，分数仍有 0.535，
只下降 0.012。按照官方方法遮盖 50% 的高权重标签相关 TF-IDF 线索后，分数降到
0.451，下降 0.097。截断呈现逐步下降：保留前 75% 是 0.519，前 50% 是
0.491，只保留前 25% 时是 0.420，下降 0.128。

因此，我们的机制层解释是：SBERT 对精确的局部词序不太敏感，但比较依赖分布在
文本中的类型相关线索，也依赖足够完整的剧情覆盖。对这个任务而言，它更像一个
“语义化的上下文线索袋”。这并不是说 SBERT 没有语义能力，也不是证明它已经
完全理解语言，而是从固定模型干预实验得到的、较为谨慎的任务层结论。

我的部分贡献不只是训练一个语义分类器，还包括阈值选择、成功和失败案例分析，
以及通过官方六组干预数据研究模型究竟依赖什么信息。
